## Retrieval
A few hundred pages ≈ 0.3-0.6M tokens: do not put everything in the prompt (above 100k tokens Haiku 5.5 costs 5x per token). FTS: stored generated tsvector, GIN index, websearch_to_tsquery, ts_rank in an RPC; heading weight A, body B (1P supabase.com/docs/guides/database/full-text-search). Chunk by h2/h3, keep heading path, split chunks over ~600 tokens at paragraph breaks, store page id and character offsets; top 6 chunks. Embeddings only if recall@6 < ~90%: Supabase hybrid search with RRF (1P supabase.com/docs/guides/ai/hybrid-search), gte-small 384 dims in an Edge Function (docs from 2024, recheck), Gemini Embedding 2 $0.20/M tokens, OpenAI 3-small $0.02/M; indexing 0.5M tokens costs $0.01-0.10. Gemini File Search tool (managed, 1 GB free store, Markdown supported) ties us to Google with coarse citations: skip.

## Verbatim-quote verification (run on every answer)
Option A (primary): send each retrieved chunk as a `document` block with `citations: {enabled: true}`; API returns `cited_text` + location indexes. Option B (any model): JSON `{claims:[{text, chunk_id, quote}]}` or `{refuse:true}`.
1 Normalise quote and chunk: Unicode NFC, collapse whitespace, unify curly/straight quotes and dashes, strip Markdown emphasis markers. 2 Pass only if the normalised quote is a contiguous substring of the named chunk, and the chunk was one of those retrieved. 3 Reject quotes under 6 or over 80 words. 4 Display text from our database using the matched offsets, never the model's copy; link to the heading anchor. 5 If any claim fails retry once naming the failing quote; then show "No verified answer" with retrieved headings as links. 6 Substring proves existence, not support: use the golden set and an optional judge pass.

## Evaluation (~$0.03 per run of 40 on Haiku 5.5)
24 single-page facts (8 with numbers/exact strings), 6 two-page questions, 4 paraphrases with little keyword overlap, 6 unanswerable, 2 targeting a planted injection page; hand-written gold page and gold quote each. Metrics: recall@6; quote validity 100%; answer correctness ≥ 90% (owner judged); groundedness (LLM judge "does the quote entail the claim?" + human check of 10); correct refusals 6/6; false refusals ≤ 10%. Re-run after every model, prompt or chunking change; keep history. (RAG Triad per OWASP LLM01:2025.)

## Prompt injection
Documents are attacker-controlled (collaborators, AI tools). The Q&A function has no tools (one model call, no web, no writes, no MCP; text only). Never render model output as HTML/Markdown links or images; show plain text and database quotes; link only to our heading anchors. Delimit retrieved text in tagged blocks and say it is data. Retrieve under the caller's identity with RLS. Reuse the phase 6.7 scanner; keep injection items in the golden set. Residual risk: a planted real quote still passes substring: show the source page next to every answer.
